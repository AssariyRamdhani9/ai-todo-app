# 📝 AI-Powered Todo App

A full-stack todo application with AI-powered suggestions, built with Go, React, and PostgreSQL.

## ✨ Features

### Core Features
- ✅ **Authentication** - Login and Register with JWT
- ✅ **CRUD Operations** - Create, Read, Update, Delete todos
- ✅ **AI Suggestions** - Get smart tips from Groq AI for each task
- ✅ **Priority Levels** - High, Medium, Low
- ✅ **Categories** - Work, Personal, Study, Health, Other
- ✅ **Deadlines** - Set and track due dates
- ✅ **Search & Filter** - Find todos quickly
- ✅ **Sort** - By date, priority, title, deadline

### Advanced Features
- 📊 **Dashboard** - Visual analytics with charts
- 📈 **Weekly Progress** - Track productivity
- 🎯 **Stats** - Total, completed, pending, overdue
- ✏️ **Edit Todo** - Full edit capability
- 🎨 **Modern UI** - Responsive design with Tailwind CSS

## 🛠️ Tech Stack

### Backend
- **Go** 1.21+ with Gin Framework
- **GORM** for ORM
- **PostgreSQL** for database
- **JWT** for authentication
- **Groq AI API** for smart suggestions

### Frontend
- **React** 18 with Vite
- **Tailwind CSS** for styling
- **Chart.js** for dashboard charts
- **Axios** for HTTP requests
- **React Modal** for modals
